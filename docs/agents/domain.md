# Docs de domínio

Contexto único (single-context):

- **`CONTEXT.md`** na raiz — glossário do domínio (KPI, meta, dimensão, perna quantitativa,
  `periodo_referencia`, coleções `camada_semantica` / `diagnostico` / `prescricao`…). Ainda não
  existe: é criado/atualizado pela skill `grill-with-docs` conforme os termos se cristalizam.
- **`docs/adr/`** — decisões contestáveis e seus porquês. Respeite os ADRs da área que você toca;
  se for contrariar um, registre um ADR novo que o substitua.
